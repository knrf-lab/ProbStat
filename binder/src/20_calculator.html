C · Casio fx-991ID calculator guide

Your model has DIST mode with Normal PD/CD, Inverse Normal, Binomial PD/CD and Poisson PD/CD. Menu numbers can differ slightly between versions, so select by name. Each block has a check value: run it once tonight to confirm the input order on your unit.

Turning CD output into what is asked (discrete X): P(X = k) = PD(k) · P(X ≤ k) = CD(k) · P(X < k) = CD(k−1) · P(X ≥ k) = 1 − CD(k−1) · P(X > k) = 1 − CD(k) · P(a ≤ X ≤ b) = CD(b) − CD(a−1)
Use DIST to check answers. On paper, still write the formula, the substitution and the z-value. The z-table method is what the class boards show (Z rounded to 2 decimals). The table answer can differ from the calculator in the 3rd decimal. Both are fine; say which you used.

2 · Integration (COMP mode): ∫▭dx key

  • MODE COMP, press ∫▭, type f(x) using ALPHA) for X, then the lower and upper limits with the arrow keys, then =.
  • Check: \(\int_3^4 (0.075x+0.2)\,dx\) → 0.4625. \(\int_3^5 x(0.075x+0.2)\,dx\) → 4.05.
  • For an infinite limit, do the tail analytically or use a finite limit far into the tail (e.g. \(\int_{0.5}^{200}\)), then confirm the answer stops changing. Avoid 10^99 inside ∫, because the numeric integrator can fail.
  • The class integrated the normal pdf directly with ∫. This works if the limits are within about 6σ of μ, e.g. \(\int_{485}^{515}\frac{1}{\sqrt{2\pi\cdot64}}e^{-\frac12((x-500)/8)^2}dx = 0.9392\). Normal CD is faster.

3 · Solve for a percentile / median: SHIFTCALC (SOLVE)

Type the equation \(F(x)=p\) with ALPHACALC for "=". Example (median of the Practice Quiz Q6 pdf): (X²/2+X−1.5)/6 = 0.5 → SHIFT CALC, start guess 2 → X = 2.1623. If two roots exist, give a starting guess inside the support [A, B].

4 · STAT mode for data: MODE → STAT → 1-VAR

  • Enter the data in column x (= after each value), press AC, then SHIFT1 (STAT) → Var: n, x̄, σx (population, ÷N), sx (sample, ÷(n−1)). Use sx for a sample; square it for s².
  • Sum menu: Σx and Σx². These are useful to show the calculational formula on paper.
  • Frequency column (setup: SHIFTMODE → STAT → Frequency On). For a pmf table, put x in column X and p(x) in FREQ. Then x̄ = E(X) and σx = σ of the random variable. Check with the dice-difference table: x̄ = 1.9444, σx² = 2.0525. If your unit rejects decimal frequencies, use counts instead (6, 10, 8, 6, 4, 2 out of 36). The answer is the same.
  • Check for data: 2, 9, 11, 5, 6 → x̄ = 6.6, sx = 3.5071.
