6 · Exponential distribution (distribusi eksponensial)

\(X\sim \mathrm{Exp}(\lambda)\), where λ > 0 is the rate (laju). Domain x ≥ 0. \[f(x)=\lambda e^{-\lambda x},\ x\ge 0\qquad F(x)=1-e^{-\lambda x}\] \(\P(X>x)=e^{-\lambda x}\) · \(\P(a\le X\le b)=e^{-\lambda a}-e^{-\lambda b}\)
\(\E(X)=\dfrac1\lambda\), \(\Var(X)=\dfrac1{\lambda^2}\), σ = mean
Median \(=\dfrac{\ln 2}{\lambda}\approx 0.693\times\text{mean}\) (less than the mean, because it is skewed right)
Used for waiting times, lifetimes, and time between events.
"Rata-rata waktu 90 menit" is the MEAN, so λ = 1/90 per minute. The class board first wrote "λ = rata-rata", then corrected it to E(X) = 1/λ. If you are given a rate ("3 per jam", 3 per hour), then λ = 3 and the mean is 1/3 hour.
Link to Poisson: if events occur at rate λ per unit time (a Poisson process), the time T until the next event is Exp(λ):
\(\P(T>t)=\P(\text{0 events in }[0,t])=e^{-\lambda t}\).
Example: 2 calls per hour. P(wait more than 1 hour) = e⁻² = 0.1353. P(next call within 15 min) = 1 − e^(−2·0.25) = 0.3935.

Memoryless property

\[\P(X\ge t+t_0\mid X\ge t_0)=\P(X\ge t)=e^{-\lambda t}\] How long it has already lasted does not matter. Only the additional time t counts.
Light bulb (Devore p.172 type): mean life 1000 h. P(it lasts another 500 h given it has already lasted 1000 h) = e^(−500/1000) = 0.6065, the same as for a new bulb.
Exam: P(X > 120 | X > 60) = e^(−60/90) = 0.5134.

Functions of a continuous random variable: Y = g(X)

CDF method (always works):
1. Find the range of Y.
2. \(F_Y(y)=\P(Y\le y)=\P(g(X)\le y)\). Rewrite this as an event about X and use \(F_X\).
3. \(f_Y(y)=F_Y'(y)\).
Monotone g (shortcut): \(f_Y(y)=f_X(g^{-1}(y))\left|\dfrac{d}{dy}g^{-1}(y)\right|\).
Only E(Y) needed? Use LOTUS: \(\E[g(X)]=\int g(x)f_X(x)\,dx\). There is no need for \(f_Y\).
Ex. X ~ U(0, 1), Y = e^X. Range [1, e]. \(F_Y(y)=\P(X\le \ln y)=\ln y\), so \(f_Y(y)=1/y\) on [1, e]. E(Y) = ∫₀¹ eˣ dx = e − 1.
Ex. X ~ U(−1, 1), Y = X². \(F_Y(y)=\P(-\sqrt y\le X\le\sqrt y)=\sqrt y\), so \(f_Y=\dfrac{1}{2\sqrt y}\) on (0, 1].
Linear: Y = aX + b: E = aμ + b, Var = a²σ². If X is Normal, Y ~ N(aμ + b, a²σ²).
Ex. (reading): X ~ N(2, 4), Y = 3 − 2X ~ N(−1, 16).
