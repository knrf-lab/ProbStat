D · Distribution picker

X is a COUNT (0, 1, 2, …)
  • n trials, success/failure, same p, independent → Binomial · {{p:s3-binom}}
  • n drawn without replacement from a small lot → Hypergeometric · {{p:s3-hyper}}
  • events per time/space at an average rate, no fixed n → Poisson · {{p:s3-pois}}
  • a custom experiment (dice, coins, a given table) → build the pmf · {{p:s3-pmf}}
X is a MEASUREMENT (time, weight, temperature)
  • formula f(x) given → integrate · {{p:s4-pdf}}
  • equally likely on [A, B] → Uniform · {{p:s4-unif}}
  • bell-shaped, mean and variance given → Normal · {{p:s5-z}}
  • waiting time / lifetime → Exponential, λ = 1/mean · {{p:s6-exp}}
