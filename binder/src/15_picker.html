D · Distribution picker

Is X a COUNT (0, 1, 2, …) or a MEASUREMENT (time, weight, length, score)?
COUNT = discrete
Is there a fixed number of trials n?
  • Yes, n trials, each success/failure, same p, independent (with replacement, or a huge population)
    → Binomial B(n, p) · {{p:s3-binom}}
  • Yes, but drawn without replacement from a small lot of N items, M of them "successes"
    → Hypergeometric · {{p:s3-hyper}}
    Rule of thumb: if n/N ≤ 0.05 the Binomial is a fine approximation.
No fixed n, counting events in an interval of time/space at an average rate
→ Poisson(λ) · {{p:s3-pois}}
  • λ must match the interval asked: 4 per hour → λ = 2 per 30 min.
Counting trials until the 1st (or r-th) success
→ Geometric / Negative Binomial · {{p:s3-geo}}

A small custom experiment (dice, coins, a given table)
→ build the pmf table yourself · {{p:s3-pmf}}
MEASUREMENT = continuous
A formula f(x) is given
→ general pdf: integrate · {{p:s4-pdf}}

"Equally likely anywhere between A and B" / "seragam"
→ Uniform[A, B] · {{p:s4-unif}}

Bell-shaped, given mean and variance (or SD); heights, weights, thicknesses, scores
→ Normal N(μ, σ²) · {{p:s5-z}}

Waiting time / lifetime / time between events, x ≥ 0, "rata-rata waktu …"
→ Exponential(λ), λ = 1/mean · {{p:s6-exp}}

Binomial with large n (np ≥ 5, n(1−p) ≥ 5) and no table/calculator support
→ Normal approximation with continuity correction · {{p:s5-approx}}

CDFs you can write directly
Uniform: \(F(x)=\dfrac{x-A}{B-A}\), A ≤ x ≤ B
Exponential: \(F(x)=1-e^{-\lambda x}\), so \(\P(X>x)=e^{-\lambda x}\)
Normal: \(F(x)=\Phi\!\left(\dfrac{x-\mu}{\sigma}\right)\) (z-table)
Binomial / Poisson: sum the pmf, or use the tables / CD
Rules for any X
\(\E(aX+b)=a\E(X)+b\)
\(\Var(aX+b)=a^2\Var(X)\) (the +b disappears!)
\(\Var(X)=\E(X^2)-[\E(X)]^2\)
\(\sigma=\sqrt{\Var(X)}\) (always ≥ 0)
Continuous: \(\P(X=a)=0\) so ≤ and < are the same
