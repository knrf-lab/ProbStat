5 · Normal distribution (distribusi normal)

\(X\sim N(\mu,\sigma^2)\) with parameters μ (mean, −∞ < μ < ∞) and σ² (variance) > 0. Domain (−∞, ∞). \[f(x)=\frac{1}{\sqrt{2\pi\sigma^2}}\,e^{-\frac12\left(\frac{x-\mu}{\sigma}\right)^2}\] \(\P(X\le x)=\int_{-\infty}^{x}f(t)\,dt\). This has no closed form, so we standardize and use the z-table (or Normal CD).
The curve is bell-shaped and symmetric about μ: mean = median = mode. A larger σ makes it wider and flatter.
N(500, 64) means σ² = 64, so σ = 8. The class writes the variance as the second parameter. Always take the square root before standardizing. If the question says "simpangan baku 8", then σ = 8 directly.
Empirical rule: P(|Z| ≤ 1) = 0.6826, P(|Z| ≤ 2) = 0.9544, P(|Z| ≤ 3) = 0.9974.
Symmetry: Φ(−z) = 1 − Φ(z); P(Z > z) = Φ(−z).

2. Find z in the body of the table with area closest to it. If it is halfway between two entries, average the z values.
3. \(x=\mu+z\sigma\). In general \(\eta(p)=\mu+z_p\,\sigma\).

Normal approximation to the Binomial

If X ~ B(n, p) with np ≥ 5 and n(1 − p) ≥ 5 (slides: "both greater than 5"; Devore uses 10), then X ≈ N(μ = np, σ² = np(1 − p)).
Continuity correction: each integer k covers [k − 0.5, k + 0.5].

P(X > k)P(Y ≥ k + 0.5)
P(X = k)P(k − 0.5 ≤ Y ≤ k + 0.5)
P(a ≤ X ≤ b)P(a − 0.5 ≤ Y ≤ b + 0.5)
Slides: n = 30, p = 0.4: np = 12, nq = 18, so the approximation is OK. σ = √7.2 = 2.683. P(X ≤ 10) ≈ P(Y ≤ 10.5) = Φ((10.5 − 12)/2.683) = Φ(−0.56) = 0.2877 (exact Binomial 0.2915).
Batteries: n = 200, p = 0.95: np = 190, nq = 10, so OK. σ = √9.5 = 3.082. P(X ≥ 195) ≈ P(Y ≥ 194.5) = 1 − Φ(1.46) = 1 − 0.9279 = 0.0721 (exact 0.0623; nq is small, so the approximation is rough).
