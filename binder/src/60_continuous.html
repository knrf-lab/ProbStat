4 · Continuous random variables (Sessions 9–12, Devore Ch. 4)

X takes any real value in an interval (bilangan real, dinyatakan dalam interval / range): midterm score 0 ≤ x ≤ 100, height 140 ≤ y ≤ 200, room temperature 20 ≤ z ≤ 38.

Probability density function (pdf)

\[\P(a\le X\le b)=\int_a^b f(x)\,dx\quad(\text{area under } f)\] f is a valid pdf iff (syarat pdf):
(1) \(f(x)\ge 0\) for all x, and (2) \(\int_{-\infty}^{\infty}f(x)\,dx=1\).
Consequences: \(\P(X=a)=0\), so
\(\P(a\le X\le b)=\P(a<X<b)=\P(a\le X<b)=\dots\)
f(x) itself is not a probability and can be > 1.

"Buktikan … pdf" / "find c": template

  1. State that f(x) ≥ 0 on the support (e.g. "e^(·) > 0 and 0.15 > 0", or check the endpoints of a linear f).
  2. Integrate over the support only (f = 0 elsewhere): \(\int_{-\infty}^{\infty}f=\int_{\text{support}}f+\int_{\text{elsewhere}}0\).
  3. Show the result = 1 (or solve c from "= 1").
  4. Conclude: "∴ f(x) merupakan pdf" (∴ f(x) is a pdf).
If ∫ f ≠ 1, the function is not a pdf. Do not "fix" it by dividing by the total area unless the question says f is proportional to … (∝). See the class example on {{p:s4-ex}}.
class board / Devore Ex. 4.5Contoh soal 1: prove that \(f(x)=0.15e^{-0.15(x-0.5)}\) for x ≥ 0.5 (0 otherwise) is a pdf. (time headway between cars)
(1) For x ≥ 0.5, 0.15 > 0 and the exponential is > 0, so f(x) ≥ 0. Elsewhere f = 0 ≥ 0.
(2) \(\displaystyle\int_{-\infty}^{\infty}f(x)dx=\int_{0.5}^{\infty}0.15e^{-0.15(x-0.5)}dx=\Big[-e^{-0.15(x-0.5)}\Big]_{0.5}^{\infty}=0-(-e^{0})=1\) ✓ ∴ f is a pdf.
Extra: P(X ≤ 5) = \(\big[-e^{-0.15(x-0.5)}\big]_{0.5}^{5}=1-e^{-0.675}=\mathbf{0.4908}\). cdf: \(F(x)=1-e^{-0.15(x-0.5)}\) for x ≥ 0.5. This is an exponential distribution with λ = 0.15 shifted right by 0.5, so E(X) = 0.5 + 1/0.15 = 7.1667 and Var(X) = 1/0.15² = 44.44.

Cumulative distribution function (cdf) (fungsi kumulatif)

\[F(x)=\P(X\le x)=\int_{-\infty}^{x}f(t)\,dt\] \(\P(a\le X\le b)=F(b)-F(a)\) · \(\P(X>a)=1-F(a)\)
\(f(x)=F'(x)\) wherever the derivative exists
F is continuous and non-decreasing, with F(−∞) = 0 and F(∞) = 1.
Writing a piecewise cdf (support [A, B]): \(F(x)=\begin{cases}0 & x<A\\ \int_A^x f(t)\,dt & A\le x\le B\\ 1 & x>B\end{cases}\)
Check: the middle piece must be 0 at x = A and 1 at x = B.
slides / Devore Ex. 4.7Gravel sales (tons/week): \(f(x)=1.5(1-x^2)\), 0 ≤ x ≤ 1.
\(F(x)=\int_0^x 1.5(1-t^2)dt=1.5\left(x-\dfrac{x^3}{3}\right)\) for 0 ≤ x ≤ 1 (0 below, 1 above).
P(X ≤ 0.25) = 1.5(0.25 − 0.005208) = 0.3672; P(X > 0.75) = 1 − 1.5(0.75 − 0.140625) = 0.0859; P(0.25 < X < 0.75) = 0.9141 − 0.3672 = 0.5469
E(X) = \(\int_0^1 x\cdot1.5(1-x^2)dx=1.5\left(\tfrac12-\tfrac14\right)=\mathbf{0.375}\); E(X²) = 1.5(1/3 − 1/5) = 0.2; Var = 0.2 − 0.375² = 0.0594; σ = 0.2437

Percentiles and the median

The (100p)-th percentile η(p) solves \(F(\eta(p))=p\).
Median \(\tilde\mu\): \(F(\tilde\mu)=0.5\). Quartiles: F = 0.25 and F = 0.75.
For a symmetric pdf, median = mean = centre of symmetry.
Gravel, 40th percentile: 1.5(η − η³/3) = 0.4 → η³ − 3η + 0.8 = 0 → η = 0.2735 (SHIFT SOLVE, start at 0.3). Median: 1.5(m − m³/3) = 0.5 → m = 0.3473.

Expected value and variance (continuous)

\[\mu=\E(X)=\int_{-\infty}^{\infty}x\,f(x)\,dx\]\[\E[h(X)]=\int h(x)f(x)\,dx\] \[\sigma^2=\Var(X)=\int(x-\mu)^2f(x)\,dx=\E(X^2)-\mu^2\] \(\E(X^2)=\int x^2f(x)\,dx\) · the rules for aX + b are the same as in the discrete case.
Each integral runs over the support only. Remember the extra x (or x²) inside. The most common slip is computing ∫ f(x) dx (= 1) when you meant ∫ x·f(x) dx.

Uniform distribution (distribusi seragam): X ~ U[A, B]

\(f(x)=\dfrac{1}{B-A}\) for A ≤ x ≤ B · \(F(x)=\dfrac{x-A}{B-A}\)
\(\P(c\le X\le d)=\dfrac{d-c}{B-A}\) (length ratio)
\(\E(X)=\dfrac{A+B}{2}\), \(\Var(X)=\dfrac{(B-A)^2}{12}\), median = (A + B)/2
Tire imperfection angle (slides): X ~ U[0, 360). P(within 90° of the reference line) = P(0 ≤ X ≤ 90) + P(270 ≤ X < 360) = 90/360 + 90/360 = 0.5.
Bus every 20 min: wait W ~ U[0, 20]. P(W > 15) = 5/20 = 0.25. E = 10 min, Var = 400/12 = 33.33.
