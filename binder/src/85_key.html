The "→ p." links point to the binder page with the method. Answers are given to 4 decimals. A z-table answer may differ from Normal CD in the 3rd–4th decimal, and both are accepted.

1. Contingency table → {{p:s2-table}}
Totals: F = 90, M = 110, L = 150, TL = 50, N = 200.
(a) P(F ∩ L) = 72/200 = 0.36 (b) P(L) = 150/200 = 0.75 (c) P(L | F) = 72/90 = 0.80 (d) P(F | TL) = 18/50 = 0.36
(e) P(F ∪ L) = (90 + 150 − 72)/200 = 168/200 = 0.84
(f) P(L | F) = 0.80 ≠ P(L) = 0.75. Equivalently, P(F)P(L) = 0.45 × 0.75 = 0.3375 ≠ 0.36. So F and L are not independent: female students pass at a higher rate.
2. Normal → {{p:s5-z}}, {{p:s5-back}}
X ~ N(500, 25), so σ = 5 (not 25!).
(a) z = (490 − 500)/5 = −2.00 → Φ(−2.00) = 0.0228
(b) z = −1.00 and 2.00 → 0.9772 − 0.1587 = 0.8185
(c) z = 12/5 = 2.40 → 1 − 0.9918 = 0.0082
(d) Heaviest 10% means a left area of 0.90, so z = 1.28 and x = 500 + 1.28(5) = 506.4 g (Inverse Normal: 506.41)
3. Discrete table → {{p:s3-pmf}}, {{p:s3-ev}}
(a) 0.1 + k + 2k + 0.3 = 1 → k = 0.2, so the table is 0.1, 0.2, 0.4, 0.3.
(b) P(X ≥ 2) = 0.4 + 0.3 = 0.7; F(1.5) = P(X ≤ 1.5) = P(0) + P(1) = 0.3
(c) E(X) = 0 + 0.2 + 0.8 + 0.9 = 1.9; E(X²) = 0 + 0.2 + 1.6 + 2.7 = 4.5; Var(X) = 4.5 − 1.9² = 0.89
(d) E(Y) = 3(1.9) − 2 = 3.7; Var(Y) = 3²(0.89) = 8.01 (the −2 does not change the variance)
4. Descriptive → {{p:s1-mean}}, {{p:s1-quart}}
Sorted: 4 5 5 5 6 6 7 7 8 9 12 30 (n = 12), Σx = 104, Σx² = 1450.
(a) x̄ = 104/12 = 8.6667; median position 6.5 → (6 + 7)/2 = 6.5; mode = 5
(b) \(s^2=\frac{1450-104^2/12}{11}=\frac{548.667}{11}=\) 49.8788, s = 7.0625 (STAT: sx)
(c) Q1 position 0.25(13) = 3.25 → 5 + 0.25(5 − 5) = 5; Q3 position 9.75 → 8 + 0.75(9 − 8) = 8.75; IQR = 3.75
(d) LL = 5 − 5.625 = −0.625, UL = 8.75 + 5.625 = 14.375, so 30 is an outlier
(e) Mean > median, so the distribution is skewed right because of the outlier. The median is the better measure of centre: without the 30, x̄ = 6.73 but the median barely moves, to 6.
5. Poisson → {{p:s3-pois}}
X = number of calls per hour, X ~ Poisson(4).
(a) P(X = 2) = e⁻⁴4²/2! = 0.1465
(b) P(X ≤ 3) = e⁻⁴(1 + 4 + 8 + 10.667) = 0.0183 + 0.0733 + 0.1465 + 0.1954 = 0.4335
(c) 30 minutes, so λ = 2: P(Y ≥ 1) = 1 − e⁻² = 0.8647
(d) P(X > 5) = 1 − P(X ≤ 5) = 1 − 0.7851 = 0.2149 (Poisson CD x = 5, μ = 4)
6. General pdf → {{p:s4-pdf}}, {{p:s4-cdf}}, {{p:s4-pct}}
(a) \(\int_1^3 c(x+1)dx=c\big[\tfrac{x^2}{2}+x\big]_1^3=c(7.5-1.5)=6c=1\Rightarrow\) c = 1/6. f ≥ 0 on [1, 3] ✓
(b) \(\P(X\le2)=\tfrac16\big[\tfrac{x^2}{2}+x\big]_1^2=\tfrac16(4-1.5)=\) 0.4167; P(1.5 < X < 2.5) = F(2.5) − F(1.5) = 0.6875 − 0.1875 = 0.5
(c) \(F(x)=\begin{cases}0 & x<1\\ \frac{x^2+2x-3}{12} & 1\le x\le3\\ 1 & x>3\end{cases}\). Check: F(1) = 0 and F(3) = 12/12 = 1 ✓
(d) \(\mu=\tfrac16\int_1^3(x^2+x)dx=\tfrac16\big[\tfrac{x^3}{3}+\tfrac{x^2}{2}\big]_1^3=\tfrac16\left(13.5-\tfrac56\right)=\tfrac{19}{9}=\) 2.1111
\(\E(X^2)=\tfrac16\big[\tfrac{x^4}{4}+\tfrac{x^3}{3}\big]_1^3=\tfrac16\left(29.25-\tfrac{7}{12}\right)=\tfrac{43}{9}=4.7778\); σ² = 43/9 − (19/9)² = 26/81 = 0.3210
(e) F(m) = 0.5 → m² + 2m − 3 = 6 → m² + 2m − 9 = 0 → m = −1 + √10 = 2.1623 (take the root inside [1, 3])
7. Total probability + Bayes → {{p:s2-total}}
(a) P(D) = 0.5(0.02) + 0.3(0.03) + 0.2(0.05) = 0.010 + 0.009 + 0.010 = 0.029
(b) P(C | D) = 0.010/0.029 = 0.3448
(c) P(A | D) = 0.3448, P(B | D) = 0.3103, P(C | D) = 0.3448. A and C are tied as the most likely source. A has the lowest defect rate but makes the most products. Check: the three add to 1.
8. Binomial → {{p:s3-binom}}
X = number of defective components, X ~ B(12, 0.1).
(a) \(\binom{12}{2}(0.1)^2(0.9)^{10}=66(0.01)(0.3487)=\) 0.2301
(b) P(0) + P(1) = 0.2824 + 0.3766 = 0.6590
(c) P(X ≥ 3) = 1 − P(X ≤ 2) = 1 − (0.6590 + 0.2301) = 0.1109
(d) 1 − P(0) = 1 − 0.9¹² = 0.7176
(e) μ = 12(0.1) = 1.2; σ = √(12 · 0.1 · 0.9) = √1.08 = 1.0392
9. Exponential → {{p:s6-exp}}, {{p:s6-mem}}
Mean 1000, so λ = 1/1000 = 0.001 per hour.
(a) P(X < 500) = 1 − e^(−0.5) = 0.3935 (b) P(X > 1500) = e^(−1.5) = 0.2231
(c) Memoryless: P(X > 1500 | X > 1000) = P(X > 500) = e^(−0.5) = 0.6065
(d) Median = ln 2/λ = 693.15 h
10. Counting → {{p:s2-count}}
(a) Ways = C(10, 4) = 210. P(exactly 2 women) = C(4,2)·C(6,2)/210 = 6·15/210 = 0.4286. P(at least 1 woman) = 1 − C(6,4)/210 = 1 − 15/210 = 0.9286
(b) The roles are different, so order matters: P(5, 3) = 5·4·3 = 60
11. Hypergeometric → {{p:s3-hyper}}
N = 15, M = 4 broken, n = 5.
(a) \(\P(X=1)=\frac{\binom41\binom{11}{4}}{\binom{15}{5}}=\frac{4\cdot330}{3003}=\) 0.4396
(b) 1 − P(X = 0) = 1 − C(11,5)/C(15,5) = 1 − 462/3003 = 0.8462
(c) E(X) = 5(4/15) = 1.3333; Var(X) = (10/14)(5)(4/15)(11/15) = 0.6984
12. Prove pdf → {{p:s4-pdf}}
(1) For x ≥ 1, 0.2 > 0 and e^(·) > 0, so f(x) > 0. Elsewhere f = 0. So f ≥ 0 ✓
(2) \(\int_{-\infty}^{\infty}f=\int_1^\infty 0.2e^{-0.2(x-1)}dx=\big[-e^{-0.2(x-1)}\big]_1^\infty=0-(-1)=1\) ✓ ∴ f is a pdf.
P(X > 6) = \(\big[-e^{-0.2(x-1)}\big]_6^\infty=e^{-1}=\) 0.3679; P(2 < X < 4) = e^(−0.2) − e^(−0.6) = 0.8187 − 0.5488 = 0.2699
This is an exponential distribution with λ = 0.2 shifted to start at 1, so E(X) = 1 + 5 = 6.
13. Chebyshev and empirical rule → {{p:s1-cheb}}
(a) 54 and 86 are 70 ± 16 = 70 ± 2(8), so k = 2: at least 1 − 1/4 = 0.75
(b) 86 = μ + 2σ, so ≈ (1 − 0.95)/2 = 0.025
(c) 62 = μ − σ, 86 = μ + 2σ: ≈ 0.68/2 + 0.95/2 = 0.815 (the z-table gives 0.8185)
14. Normal approximation → {{p:s5-approx}}
X ~ B(100, 0.3). np = 30 ≥ 5 and nq = 70 ≥ 5, so the approximation is OK. μ = 30, σ = √21 = 4.5826.
(a) P(X ≤ 25) ≈ P(Y ≤ 25.5): z = (25.5 − 30)/4.5826 = −0.98 → 0.1635
(b) P(X = 30) ≈ P(29.5 ≤ Y ≤ 30.5): z = ±0.11 → 0.5438 − 0.4562 = 0.0876
(c) Exact: Binomial CD(25; 100, 0.3) = 0.1631, Binomial PD(30) = 0.0868. The approximation is very close.
15. Uniform → {{p:s4-unif}}
(a) (20 − 15)/20 = 0.25 (b) (12 − 5)/20 = 0.35 (c) μ = 10 min, σ² = 20²/12 = 33.33
16. Independence → {{p:s2-union}}, {{p:s2-indep}}
(a) 1 − P(none) = 1 − 0.15³ = 0.9966
(b) B(3, 0.85): 3(0.85)²(0.15) = 0.3251
(c) No. They can happen together: P(both) = 0.85² = 0.7225 ≠ 0. The alarms are independent but not mutually exclusive.
