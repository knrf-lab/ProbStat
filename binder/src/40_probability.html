Sample spaces and events

  • Experiment (percobaan): a process that produces an outcome. Sample space S (ruang sampel): the set of all simple outcomes.
  • Event (kejadian): a subset of S, written with a capital letter.
  • \(A\cup B\): A or B or both (gabungan). \(A\cap B\): both (irisan). \(A^c\) (also A′): not A (komplemen).
  • Mutually exclusive (saling lepas): \(A\cap B=\emptyset\), so P(A ∩ B) = 0.
  • De Morgan: \((A\cup B)^c=A^c\cap B^c\), \((A\cap B)^c=A^c\cup B^c\).

Axioms and basic rules

1. \(\P(A)\ge 0\) · 2. \(\P(S)=1\) · 3. If \(A_1, A_2,\dots\) are mutually exclusive: \(\P(\cup A_i)=\sum \P(A_i)\)
→ \(0\le \P(A)\le 1\), \(\P(\emptyset)=0\), \(\P(A^c)=1-\P(A)\)
Equally likely outcomes: \(\P(A)=\dfrac{n(A)}{n(S)}\)

Relative-frequency interpretation: P(A) is the long-run proportion n(A)/n as n → ∞.

Board: n(S) = 100 people, n(A) = 25 wear glasses → P(A) = 25/100 = 0.25.

Addition rule, complement, "at least one"

\[\P(A\cup B)=\P(A)+\P(B)-\P(A\cap B)\] Mutually exclusive: \(\P(A\cup B)=\P(A)+\P(B)\)
Three events: \(\P(A\cup B\cup C)=\P(A)+\P(B)+\P(C)-\P(AB)-\P(AC)-\P(BC)+\P(ABC)\)
"At least one" (sedikitnya satu): \(\P(\ge 1)=1-\P(\text{none})\)
If the trials are independent with success prob p each: \(1-(1-p)^n\).
Example: 3 independent alarms each detect with 0.85: \(1-0.15^3=0.9966\).
Example (slides): 120 students. A = Javanese (50), B = female (60), both = 30. \(\P(A\cup B)=\frac{50+60-30}{120}=\frac{80}{120}=\frac23\).

Conditional probability (peluang bersyarat)

\[\P(A\mid B)=\frac{\P(A\cap B)}{\P(B)},\qquad \P(B)>0\] \(\P(A\mid B)\ne \P(B\mid A)\) in general, but \(\P(A\cap B)=\P(B\cap A)\).
\(\P(A^c\mid B)=1-\P(A\mid B)\)
Example (slides): 5 M&Ms, 2 red and 3 blue, draw 2 without replacement.
P(2nd red | 1st blue) = 2/4 = 1/2; P(2nd red | 1st red) = 1/4. The answer depends on the 1st draw, so the events are dependent.

Independence (saling bebas) vs mutually exclusive (saling lepas)

A and B are independent if any one of these holds (then all do):
1. \(\P(A\mid B)=\P(A)\) · 2. \(\P(B\mid A)=\P(B)\) · 3. \(\P(A\cap B)=\P(A)\P(B)\)
If A and B are independent, so are \(A^c\) and \(B\), \(A\) and \(B^c\), and \(A^c\) and \(B^c\).
Mutually exclusive events with P(A), P(B) > 0 are never independent: P(A ∩ B) = 0 ≠ P(A)P(B). "Saling lepas" is about overlap. "Saling bebas" is about one event giving no information about the other.

Multiplication rule

\(\P(A\cap B)=\P(A)\,\P(B\mid A)=\P(B)\,\P(A\mid B)\)
Independent: \(\P(A\cap B)=\P(A)\P(B)\)
Chain: \(\P(A\cap B\cap C)=\P(A)\P(B\mid A)\P(C\mid A\cap B)\)
Example (slides): 10% high-risk. 3 people: P(exactly one high-risk) = HNN + NHN + NNH = 3(0.1)(0.9)² = 0.243. This is the Binomial B(3, 0.1) at x = 1.
49% female, P(H | F) = 0.08 → P(H ∩ F) = 0.49 × 0.08 = 0.0392.

Law of total probability

If \(B_1,\dots,B_k\) are mutually exclusive and exhaustive (a partition: exactly one happens): \[\P(A)=\sum_{i=1}^k \P(B_i)\,\P(A\mid B_i)\] Draw a tree: the first branches are \(B_i\) with \(\P(B_i)\), the second branches are A | \(B_i\). Multiply along each path, then add the paths that end in A.
Bayes' rule \[\P(B_j\mid A)=\frac{\P(B_j)\,\P(A\mid B_j)}{\sum_i \P(B_i)\,\P(A\mid B_i)}=\frac{\text{the one path}}{\text{all paths to }A}\] Prior \(\P(B_j)\) → posterior \(\P(B_j\mid A)\) after observing A.
Example (slides): heart attack risk. P(F) = 0.49, P(M) = 0.51, P(H | F) = 0.08, P(H | M) = 0.12. A randomly selected person is high-risk. P(male)?
P(H) = 0.49(0.08) + 0.51(0.12) = 0.0392 + 0.0612 = 0.1004
\(\P(M\mid H)=\dfrac{0.0612}{0.1004}=\mathbf{0.6096}\); \(\P(F\mid H)=0.3904\). Check: the two add to 1.
Template: machines. Machines A, B, C make 50%, 30%, 20% of the output, with defect rates 2%, 3%, 5%.
P(D) = 0.5(0.02) + 0.3(0.03) + 0.2(0.05) = 0.010 + 0.009 + 0.010 = 0.029
P(C | D) = 0.010/0.029 = 0.3448 · P(B | D) = 0.3103 · P(A | D) = 0.3448
Bayes in a table: build a table of joint probabilities, \(\P(B_i)\P(A\mid B_i)\) for A and for \(A^c\). Then every posterior is "cell ÷ column total", exactly like the contingency tables above.
