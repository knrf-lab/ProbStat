3 · Discrete random variables (Sessions 5–8, Devore Ch. 3)

Random variable (variabel random)

A function that maps each outcome of an experiment to a number (fungsi yang memetakan outcome ke bilangan). It is written with a capital letter (X), and its values with a lower-case letter (x).

  • Pass/fail status: X = {lulus, tidak lulus} → coded {1, 0}. This is a Bernoulli random variable.
  • Number of phones owned: X = {0, 1, 2, …} → discrete.
  • Midterm score 0 ≤ Z ≤ 100 (any real number) → continuous (Ch. 4).

pmf and cdf

pmf (fungsi peluang / probability mass function): \(p(x)=\P(X=x)\)
Valid if: \(0\le p(x)\le 1\) and \(\sum_x p(x)=1\).
cdf (fungsi kumulatif): \(F(x)=\P(X\le x)=\sum_{y\le x}p(y)\). It is a step function, non-decreasing, rising from 0 to 1.
\(\P(a\le X\le b)=F(b)-F(a^-)\), where \(a^-\) is the possible value just below a.
\(p(x)=F(x)-F(x^-)\), the size of the jump at x.

Binomial distribution (distribusi binomial): X ~ B(n, p)

Check all four conditions (class board):
1. each trial has only 2 outcomes (success/failure)
2. a fixed number of trials n
3. trials are independent
4. P(success) = p is known and constant on every trial
X = number of successes in n trials. \[\P(X=x)=\binom{n}{x}p^x(1-p)^{n-x},\quad x=0,1,\dots,n\] \(\mu=np\), \(\sigma^2=np(1-p)\) (q = 1 − p)
Sampling without replacement from a small population breaks independence, so use the Hypergeometric. If the sample is ≤ 5% of the population, the Binomial is OK (Devore).
Binomial PD (x, N, p) for P(X = x). Binomial CD for P(X ≤ x). For P(X ≥ k), use 1 − CD(k−1).
Marksman (slides): hits 80%, 5 shots. P(X = 3) = 10(0.8)³(0.2)² = 0.2048. P(X > 3) = P(4) + P(5) = 0.4096 + 0.3277 = 0.7373. μ = 4, σ = √0.8 = 0.894. Zero hits is (0 − 4)/0.894 = −4.5 SDs from the mean, so it would be very unusual.

Poisson distribution (distribusi Poisson): X ~ Poisson(λ)

X = number of events in a fixed interval of time or space (calls per hour, typos per page, accidents per week, vehicles through a toll gate).
λ = average number of events in that interval (rata-rata kejadian). \[\P(X=x)=\frac{e^{-\lambda}\lambda^x}{x!},\quad x=0,1,2,\dots\] \(\mu=\lambda\), \(\sigma^2=\lambda\)
Rescale λ: rate α per unit, interval length t → λ = αt.
Approximates the Binomial when n is large and p is small: λ = np (Devore: n > 50, np < 5).
class boardTypos: λ = 3 per page.
1. P(X = 5) = e⁻³3⁵/5! = 0.1008
2. P(X ≤ 3) = e⁻³(1 + 3 + 9/2 + 27/6) = 0.0498 + 0.1494 + 0.2240 + 0.2240 = 0.6472
3. P(X ≥ 2) = 1 − P(0) − P(1) = 1 − 0.0498 − 0.1494 = 0.8009
Accidents (slides): λ = 2 per week. P(X = 1) = 2e⁻² = 0.2707. P(X ≥ 8) = 1 − P(X ≤ 7) = 1 − 0.9989 = 0.0011.
For 2 weeks, λ = 4.

Hypergeometric distribution: sampling without replacement (tanpa pengembalian)

Population of N items, of which M are "successes". Draw n without replacement. X = number of successes in the sample. \[\P(X=x)=\frac{\binom{M}{x}\binom{N-M}{n-x}}{\binom{N}{n}}\] \(\E(X)=n\dfrac{M}{N}\), \(\Var(X)=\dfrac{N-n}{N-1}\cdot n\dfrac{M}{N}\Big(1-\dfrac{M}{N}\Big)\)
The factor (N − n)/(N − 1) is the finite-population correction. Without it, the variance is the Binomial one with p = M/N.
Batteries (slides). A pack of 8 has 2 defective. Pick 4. Success = a working battery: N = 8, M = 6, n = 4.
P(all 4 work) = \(\dfrac{\binom64\binom20}{\binom84}=\dfrac{15}{70}=\mathbf{0.2143}\)
E(X) = 4(6/8) = 3; Var(X) = (4/7)(4)(0.75)(0.25) = 0.4286.

Geometric and Negative Binomial (listed in the sub-topics; low priority)

Geometric: X = trial number of the first success. \(\P(X=x)=(1-p)^{x-1}p\), x = 1, 2, …
\(\P(X>k)=(1-p)^k\), \(\E(X)=1/p\), \(\Var(X)=(1-p)/p^2\).
Example: p = 0.1. P(first success on the 3rd try) = 0.9²(0.1) = 0.081. P(success within 3 tries) = 1 − 0.9³ = 0.271.
Negative Binomial (Devore's form): X = number of failures before the r-th success.
\(\P(X=x)=\binom{x+r-1}{r-1}p^r(1-p)^x\), \(\E(X)=\dfrac{r(1-p)}{p}\), \(\Var(X)=\dfrac{r(1-p)}{p^2}\).
Example: r = 2, p = 0.2, x = 3 failures: \(\binom41(0.2)^2(0.8)^3=0.0819\).
Other books count total trials X + r. Check which definition the question uses.

Discrete checklist

  1. Define X in words (X = banyaknya …) and list its possible values. The class boards always do this.
  2. Name the distribution and its parameters: "X ~ B(8, 0.4)", "X ~ Poisson(3)".
  3. Translate the words into an inequality (Tab G), and turn it into = / ≤ / complement form.
  4. Write the formula, substitute, and compute. Check with DIST.
  5. Sanity check: is 0 ≤ P ≤ 1? Is it near the mean, which is where the largest probabilities are?
